# Evaluation protocol
The reproducible harness compares selected pinned public upstream literal primitives (A), integrated literal discovery (B), and integrated lexical ranking (C) on identical frozen synthetic task IDs. A preserves case-sensitive first-match behavior; complete upstream team/review setup is explicitly NOT_RUN. Evidence coverage and selection are identical. Synthetic resource probes are not independent decision-quality evidence.

Run `python scripts/evaluate.py --home STATE --dataset DATASET --snapshot SNAPSHOT --tasks tests/fixtures/synthetic/evaluation-tasks.json`. Results contain measured wire bytes, retrieval completion/correctness/source recall, citation correspondence for integrated arms, calls/API requests, process RSS, Python allocation peak, storage and latency. No duplicate/closure classification is made. Token/reviewer-time/cost/model metrics remain NOT_MEASURED or NOT_RUN unless explicitly measured; no character estimates or fabricated savings.

Broader trials require at least30 independently reviewed cases from2 permitted public repositories, frozen labels/disagreements, isolated model/version/prompts/catalog/budgets and randomized order; count all failures/retries and totaltokens per correct task alongside all-task totals. Public trials, model calls, live actions and a30% savings claim are NOT_RUN. No private baseline or data enters the harness.
