# Security reporting
Report suspected security issues privately to [contact@greyforge.tech](mailto:contact@greyforge.tech). Do not include credentials, private caches, source dumps, or sensitive logs in public issues. Describe the affected version, impact, and a minimal reproduction using public or synthetic inputs. Coordinate sensitive evidence privately with the project contact.

Stop distribution if prohibited material may have been exposed; revoke affected credentials and coordinate remediation. Deleting a published file does not guarantee all copies disappear.
