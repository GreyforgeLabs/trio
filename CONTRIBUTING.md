# Contributing
Use public sources and synthetic fixtures only. Preserve donor provenance and licenses. Do not add private repositories, live caches, credentials, workstation paths, or assistant histories. Run `python -m unittest discover -s tests -v` and publication checks before proposing changes. Newly authored contributions are Apache-2.0; public contributor identities must be explicitly chosen. Do not add AI author/co-author trailers or assistant bylines. Preserve legitimate human and upstream credits. Exact release approvals are separate from source contributions.
